# 09: 歷史清單

**What to build:** 使用者在歷史頁看到過去所有討論（問題、討論模式、開始時間、結束原因），點進去以唯讀方式看完整內容（每輪發言、草案、裁定、插話、移出、結果）。

**Scope:**
- 後端：討論紀錄儲存（列表與讀取）、「取得討論列表」與「取得單一討論」端點的處理函式。
- 前端：歷史頁的頁面與元件（只能改自己的頁面與元件）。
- 不得修改熱點檔案（含前端路由、全域 store、主版面）。若需要修改討論引擎，停下回報。

**Blocked by:** 03

**Status:** resolved

- [ ] 列表依開始時間新到舊排列，欄位符合 spec
- [ ] 單一討論回傳完整紀錄 JSON
- [ ] 進行中的討論也出現在列表（outcome 為空，顯示「進行中」）
- [ ] 歷史檢視沒有任何可以繼續討論的輸入
- [ ] E2E：完成一場提問後，在歷史頁找到並打開它
