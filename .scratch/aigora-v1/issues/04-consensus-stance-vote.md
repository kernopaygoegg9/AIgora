# 04: 共識討論（方式 A：主持人 + 全員表態）

**What to build:** 使用者選擇共識討論，參與者多輪接力討論：第 1 輪自由回答，之後每輪主持人寫共識草案、所有參與者表態；全員同意就輸出共識結果，到達輪數上限就輸出各方立場與分歧點。前端顯示每輪的草案與表態。

**Scope:**
- 後端：共識討論模式、共識裁定方式 A、討論引擎（額外呼叫、輪數上限）。
- 前端：討論頁中顯示共識草案、表態、共識結果 / 分歧整理的元件。
- 不得修改熱點檔案（含前端路由、全域 store、主版面）。WebSocket 訊息型別已凍結：若需要新訊息類型，**停下回報，不要自行修改**。
