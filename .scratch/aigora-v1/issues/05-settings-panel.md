# 05: 設定面板

**What to build:** 開始討論前，使用者在設定面板中選討論模式、參與者、共識裁定方式、主持人、發言順序、輪數上限、逾時；預設值來自 `participants.toml`。參與者旁顯示可用性與「無上網」標示；不可用的選項無法選取。討論開始後設定鎖定。

**Scope:**
- 後端：「取得參與者清單」（含能力與可用性）與「取得選項與預設值」端點的處理函式。
- 前端：設定面板的元件（只能改自己的頁面與元件）。
- 不得修改熱點檔案（含前端路由、全域 store、主版面）。WebSocket 訊息型別已凍結：若需要新訊息類型，**停下回報，不要自行修改**。若需要修改討論引擎，停下回報（引擎由 04 → 06 → 07 → 08 依序擁有）。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 設定面板的預設值與 `participants.toml` 的 `[defaults]` 一致
- [ ] 依所選討論模式只顯示用得到的欄位（提問不顯示主持人、共識裁定方式、輪數上限）
- [ ] 不可用的參與者顯示原因且無法勾選；`web_access = false` 的參與者顯示「無上網」
- [ ] 不可用的共識裁定方式（例如方式 B 無金鑰）顯示為灰色並附原因
- [ ] 討論開始後設定面板鎖定
- [ ] E2E 覆蓋以上行為
