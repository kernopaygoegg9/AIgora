# 10: 提問轉共識討論

**What to build:** 提問結束後，畫面出現「開始共識討論」按鈕；按下後開啟一場新的共識討論，沿用原本的問題與參與者，原本的發言直接當作第 1 輪，從主持人寫第一份草案開始。

**Scope:**
- 後端：共識討論模式（帶入既有討論）、討論紀錄（`derived_from`）。
- 前端：提問結果上的按鈕元件（只能改自己的元件）。
- 不得修改熱點檔案（含前端路由、全域 store、主版面）。WebSocket 訊息型別已凍結：若需要新訊息類型，**停下回報，不要自行修改**。

**Blocked by:** 08、09

**Status:** resolved

- [ ] `start` 帶 `from_discussion_id` 時，新討論的第 1 輪等於原提問的發言，不再呼叫參與者
- [ ] 新討論的紀錄 `derived_from` 指向原提問；原提問紀錄不變
- [ ] 指向不存在或不是提問的討論時回傳 `error`
- [ ] E2E：提問 → 按按鈕 → 共識討論完成
