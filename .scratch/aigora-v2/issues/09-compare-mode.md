# 09: 對照模式

**Type:** 程式（tdd，前端）

**What to build:** 使用者點某個發言（或額外呼叫）的上下文標籤，這次呼叫看不到的內容（問題／主題、發言、草案、插話）全部變淡；再點一次恢復。討論中與唯讀紀錄都能用。

**Scope:**
- 依 `forgotten_through`、`question_forgotten` 與 spec 的歷史順序規則（依輪次；同一輪內插話依 `applies_before_turn` 插在對應位置之前、發言依該輪 `order`、草案在最後；被保留的最新草案不算遺忘），算出要淡化的項目。只用 store 狀態或紀錄 JSON 推導，不新增後端欄位。
- 淡化樣式、對照中的標籤標示；一次只有一個對照中的呼叫，點其他標籤即切換。
- 這次呼叫之後的內容不淡化（本來就還沒發生）。

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] E2E：設小上限讓前幾則被遺忘，點後面某則的標籤，被遺忘的發言卡片淡化、未遺忘的不淡化；再點一次恢復
- [ ] E2E：`keep_question = false` 且問題被遺忘時，問題區塊也淡化
- [ ] E2E：點另一張卡片的標籤會切換對照對象
- [ ] E2E：唯讀紀錄的對照模式結果與討論中相同
