# 07: 參與者設定視窗與人設

**Type:** 程式（tdd）

**What to build:** 使用者在設定面板點開某個參與者，跳出它的設定視窗，設定模型、人設、設為主持人；參與者表格每一列改成摘要。人設進入該參與者自己的系統提示，其他人看不到。

**Scope:**
- 前端設定頁（spec「前端 > 設定頁」）：
  - 參與者表格每列：勾選、頭像與名稱、摘要（模型、「有人設」標記、主持人 pill）、能力與可用性 pill、「設定」按鈕。原本每列的模型下拉選單移進設定視窗（沿用 ui-redesign 的模型選擇元件與自行輸入規則）。
  - 設定視窗：原生 `<dialog>` 或等效，可用鍵盤操作、Esc 關閉；模型、人設（多行、字數計數、上限 2,000）、「設為主持人」（只在討論模式需要主持人時顯示）。確定後套用、取消不變。臨時參與者也能開。
  - 右欄的主持人改為唯讀顯示。既有 E2E 依賴 `getByLabel('主持人')`：保留可存取名稱為「主持人」的元素，或依 ui-redesign spec「刻意修改的測試」規則更新測試，並在本檔 Comments 記錄原因。
  - `start` 送出 `personas`（與設定檔預設不同或空字串時）。
- 後端：Prompt Builder 的人設片段，放在系統提示的參與者名單之後，只出現在自己的 prompt；額外呼叫（草案、摘要等）也帶主持人自己的人設。
- 檢視器「設定（已鎖定）」與唯讀紀錄列出每個參與者的人設；發言卡片上不顯示。
