# 12: 提問轉共識討論改回到設定面板

**Type:** 程式（tdd）

**What to build:** 提問結束後按「開始共識討論」，回到設定面板的轉換狀態：問題、參與者與模型沿用提問並鎖定；主持人、共識裁定方式、發言順序、輪數上限、人設、上下文上限等都可以改；可以取消回到提問結果。

**Scope:**
- 前端：轉換狀態（spec「提問轉共識討論」）——討論模式固定為共識討論、問題與參與者清單與模型（含臨時參與者）唯讀、頂部標示「由提問轉換：<問題>」、「取消」回到該提問的結果畫面；其餘欄位與參與者設定視窗照常可用（模型欄位唯讀）。開始時送 `from_discussion_id`。
- 後端：`from_discussion_id` 時問題、`participant_ids`、`models`、`extra_participants` 取自原提問（請求中這幾項被忽略）；`personas`、`context_limits`、`keep_question`、主持人與其他設定取自請求，從第 2 輪開始生效；第 1 輪沿用提問的發言與當時的上下文用量。

**Blocked by:** 07, 08

**Status:** ready-for-agent

- [ ] 後端：請求中的參與者與模型和原提問不同時，仍以原提問為準
- [ ] 後端：請求中的主持人、人設、上下文上限生效於第 2 輪（prompt 與 `ContextUsage` 可證明）
- [ ] E2E：提問結束按「開始共識討論」回到設定面板，問題與參與者唯讀、主持人可以換，開始後第 1 輪是提問的發言
- [ ] E2E：按「取消」回到提問的結果畫面
- [ ] 既有的 `ask-to-consensus` E2E 依新流程更新，並在本檔 Comments 記錄原因
