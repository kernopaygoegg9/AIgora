# 03: 依序發言（提問、共識討論，依清單順序）

**Type:** 程式（tdd）

**What to build:** 使用者在設定面板為提問或共識討論選擇「依序」。同一輪一次只有一人發言，後發言者看得到同一輪前面的人剛完成的發言；畫面上同一輪的發言依順序由上往下排列。順序一律是參與者清單順序（主持人排順序是 05）。

**Scope:**
- 實作 `sequential` 發言順序並註冊，`/api/options` 標為已實作；設定面板的「依序」可以選（拿掉「尚未提供」）。
- 依序時失敗或逾時的發言照 v1 記錄，下一位照常發言並在 prompt 中看到「（沒有回覆：原因）」；停止時正在發言者被取消、其後的人不再發言。
- 前端：依序時同一輪的發言卡片依 `order` 由上往下排列、寬度填滿舞台；同時發言維持左右並排。討論中與唯讀紀錄一致（共用元件或樣式）。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 後端：依序時第 2 位的 prompt 含第 1 位本輪的發言；同時發言時不含
- [ ] 後端：依序時 `turn_started` 一次只有一個未完成的發言（訊息序列可證明）
- [ ] 後端：依序時中間一位失敗，下一位照常發言、prompt 中有「沒有回覆」；連續失敗移出規則不變
- [ ] 後端：依序時停止，正在發言者 `turn_failed`（停止原因），其後的人沒有 `turn_started`
- [ ] E2E：選依序的提問，發言卡片由上往下排列且順序與清單一致；唯讀紀錄相同
- [ ] E2E：同時發言的畫面與 v1 相同
