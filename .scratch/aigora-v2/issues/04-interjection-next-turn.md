# 04: 依序發言時插話從下一個發言生效

**Type:** 程式（tdd）

**What to build:** 依序發言時，使用者插話後，下一位尚未開始發言的參與者就看得到；插話佇列顯示「第 N 輪第 M 位起生效」。同時發言仍從下一輪生效。

**Scope:**
- 引擎依 spec「插話（依序發言）」決定生效位置：本輪還有人沒開始 → 本輪下一位；本輪最後一位正在發言或已在額外呼叫階段 → 下一輪第 1 位。
- `interjection_queued.applies_before_turn` 與紀錄 `interjections[].applies_before_turn`（同時發言或該輪第 1 位為 null）。
- Prompt 中插話出現在歷史的對應位置（該輪第 M 位發言之前）。
- 前端插話佇列：依序時「第 N 輪第 M 位起生效」，同時發言維持「第 N 輪起生效」；唯讀紀錄中插話顯示在對應的發言之前。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 後端：三人依序，第 1 位發言中插話 → 第 2 位起看得到、第 1 位看不到；`applies_before_turn = 2`
- [ ] 後端：最後一位發言中插話 → 下一輪第 1 位起生效（`applies_before_turn` 為 null）
- [ ] 後端：同時發言的插話行為與 v1 相同
- [ ] 後端：插話在之後輪次的 prompt 中出現在正確的歷史位置
- [ ] E2E：依序討論中插話，佇列顯示「第 N 輪第 M 位起生效」；唯讀紀錄中插話位於對應發言之前
